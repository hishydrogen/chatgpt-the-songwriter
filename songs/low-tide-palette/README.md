# Low Tide — 체크포인트 1

비틀즈의 「Come Together」를 분위기 참고로 삼은 새 인스트루멘털 곡의 사운드 팔레트입니다.
완성곡의 예정 길이는 사용자가 선택한 약 3분 30초입니다. `Low Tide`는 작업 제목입니다.
이 단계는 완성곡이 아니라 악기와 음색을 비교하는 오디션입니다.

체크포인트 1을 들은 사용자 선택은 **드럼 B + 베이스 B + 건반 B + 리드 B**입니다.
소리가 찢어지지 않도록 해달라는 요청도 반영해 [체크포인트 2](../low-tide-groove/README.md)에서
같은 편성의 앰프와 포화를 낮추고 출력 여유를 늘립니다.

## 곡의 방향

- 늦은 1960년대의 낮고 건조한 블루스 록 밴드: 둥근 베이스, 눌린 드럼과 낮은 톰,
  전기피아노, 기타 앰프의 약한 드라이브.
- 새 구절: 86 BPM, E단조, `Em7 / Em9 / Am7 / B7`의 4마디.
- 원곡의 음원, 멜로디, 유명한 베이스 리프는 사용하지 않습니다.
- 비교 후보마다 같은 음표, 연주 타이밍과 같은 반주를 사용합니다. 각 4마디 뒤에
  1마디 여백이 있습니다. 고음역을 부드럽게 하고 베이스는 중앙에, 건반과 기타는
  조금씩 좌우에 둡니다. 과한 스테레오 확장이나 펌핑 효과를 쓰지 않습니다.
- 샘플 악기와 디지털 처리를 이용한 시대감의 근사입니다. 원녹음과 동일한 실물 악기,
  콘솔, 테이프 머신을 확인하거나 그대로 복원했다는 의미는 아닙니다.

## 들어보기

[MP3 오디션](out/master.mp3) / [24비트 WAV](out/master.wav)

오디션 길이는 2분 9초입니다. MP3는 320 kbps이며, WAV는 24비트/48 kHz입니다.

후보의 실연은 각 구간의 처음 약 11초이며, 그 뒤에는 잔향을 비교하고 다음 후보로
넘어가기 위한 여백이 있습니다. 음량을 바꾸지 않고 비교하세요.

| 시작 | 후보 | 비교할 점 |
|---|---|---|
| 0:00 | 드럼 A | 가까운 마이크, 먹먹하고 건조한 어택 |
| 0:14 | 드럼 B | 빈티지 마이크와 조금 더 눌린 테이프 질감 |
| 0:28 | 베이스 A | 짧은 스케일의 둥글고 통통한 소리 |
| 0:42 | 베이스 B | 손가락 어택과 음정 윤곽이 더 분명한 소리 |
| 0:56 | 건반 A | 부드러운 Rhodes 전기피아노 |
| 1:10 | 건반 B | 나무처럼 마르고 거친 Wurlitzer 전기피아노 |
| 1:24 | 리드 A | 둥근 클린 기타, 가벼운 진공관 색채 |
| 1:38 | 리드 B | 앰프가 살짝 찢어지는 기타 |
| 1:52 | 리드 C | 전기피아노가 멜로디를 맡는 버전 |

추천 시작점은 **드럼 A + 베이스 A + 건반 A + 리드 B**입니다.
비교 후 각 범주의 후보를 선택하면 체크포인트 2에서 그 편성으로 8마디 그루브를
만듭니다. 이 단계에서는 전체 편곡이나 최종 제목을 확정하지 않습니다.

## 재현과 검증

```bash
source /workspace/songwriter-env/activate.sh
cd /workspace/chatgpt-the-songwriter
python songs/low-tide-palette/build.py
python scripts/audition_levels.py songs/low-tide-palette
```

`build.py`는 표준 렌더링·믹싱 파이프라인을 사용하고, 채널 처리가 끝난 후보들의
측정 음량으로 `loudness_trims.json`을 갱신합니다. 같은 범주 후보 간 음량 차이와
반주를 포함한 음량 차이를 각각 1 dB 이내로 확인하며, 음량/피크/모노 호환성도 검사합니다.
검증 결과는 `out/audition-validation.json`, 기술 리포트는 `out/report.json`과
`out/report.png`에 있습니다. 동일한 음표·타이밍·벨로시티와 MP3 디코딩 검증은
`out/export-validation.json`에 기록합니다. 이 측정은 선호 음색이나 음악성을 대신 판단하지 않습니다.

이번 결과는 후보 간 최대 차이 0.42 dB, 같은 범주의 전체 반주 간 최대 차이 0.2 dB입니다.
WAV 마스터는 -14.05 LUFS, -1.00 dBTP, PLR 13.05 dB이며 모노 호환성 경고는 없습니다.
MP3를 다시 디코딩한 피크는 -0.97 dBTP로, 인코딩 후에도 클리핑이 없습니다.
리포트의 전곡 마스킹 참고 항목 중 리드 A와 B는 서로 다른 구간에 있어 동시에 겹치지 않습니다.

참고 파일의 분석 결과는 커밋하지 않는 `refs/`에 보관합니다. 원본의 박자 분석은
약 167 BPM을 반환했지만 느린 4분음표로 해석하면 약 83-85 BPM입니다. 전곡의 음높이
통계는 D단조를 가장 높은 후보로 골랐습니다. 이 값은 원곡 리프를 추출한 결과가 아닙니다.
외부 녹음 관련 웹페이지는 이번 실행 환경에서 접근이 차단되어 장비 모델별 조사는
새로 검증하지 못했습니다.
