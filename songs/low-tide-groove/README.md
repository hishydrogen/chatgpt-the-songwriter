# Low Tide — 체크포인트 2

사용자 선택 **BBBB**를 반영한 8마디 그루브 스케치입니다. 약 3분 30초의
인스트루멘털 완성곡으로 가기 전에 리프와 리듬의 방향을 고릅니다.

## 확정한 편성

- 드럼 B: Virtuosity의 빈티지 마이크를 섞은 킷.
- 베이스 B: Darkblack의 따뜻한 손가락 베이스.
- 건반 B: Wurlitzer EP200.
- 리드 B: Emily DI 기타와 기타 앰프.
- 추가 요청: “소리 안 찢어지게 좀 조심해 주세요.”

기타는 같은 B 악기를 쓰되 앰프 입력과 드라이브를 낮춥니다. 체크포인트 1의
`PreGain -1 / Distortion 20 / Drive 0.22`를 `-8 / 4 / 0.08`로 낮췄고,
기타의 추가 테이프 포화도 뺐습니다. 드럼과 베이스, 건반의 테이프 포화는 적게
섞고, 리미터의 피크 목표를 -1.3 dBTP로 잡아 MP3 변환에도 여유를 둡니다.
샘플 렌더러의 중간 출력도 32비트 부동소수점으로 개선해, 믹싱 전 단계에서의
불필요한 양자화와 클리핑을 방지합니다. [렌더러 변경과 검증](../../docs/sfizz-float-output.md).

## 들어보기

[MP3 그루브 비교](out/master.mp3) / [24비트 WAV](out/master.wav)

비교 파일은 1분 18초이며 MP3는 320 kbps, WAV는 24비트/48 kHz입니다.

세 버전 모두 86 BPM, E단조이며 같은 8마디 화성과 중심 멜로디를 씁니다.
`Em9 / Em9 / Am9 / B7 / Em9 / G6 / Am9 / B7`.
원곡의 음원이나 베이스 리프, 멜로디는 사용하지 않습니다.
기타의 앞 2마디가 중심 리프이고, 베이스가 그 아래에서 짧게 대답합니다.
각 버전의 연주는 약 22초이며 뒤에 1마디 여백이 있습니다.

| 시작 | 그루브 | 차이 |
|---|---|---|
| 0:00 | A | 스네어를 조금 늦게 두고 묵직하게 눌러 가는 뒤박 |
| 0:25 | B | 베이스와 기타가 박자 앞을 당기는 싱코페이션 |
| 0:50 | C | 하이햇을 덜고 톰과 쉼표를 살린 여유 있는 리듬 |

이 A/B/C는 그루브 버전이며, 악기 선택 BBBB는 모든 버전에 유지합니다.
한 가지를 고르거나 “벌스 A, 후렴 B”처럼 섞을 수 있습니다.
선택한 뒤 체크포인트 3에서 전체 편곡과 러프 믹스를 만들고 제목과 엔딩을 정합니다.

## 재현과 검증

```bash
source /workspace/songwriter-env/activate.sh
cd /workspace/chatgpt-the-songwriter
python songs/low-tide-groove/build.py
```

전체 밴드의 비교 음량을 측정해 버전 간 0.6 dB 이내로 맞춥니다.
원시 스템의 풀스케일 평탄 구간, WAV 출력, MP3 재디코딩 후 피크,
다이내믹과 모노 호환성을 검사합니다. `out/validation.json`과 `out/report.*`에
기록합니다. 피크 검증은 디지털 클리핑을 확인하며 음색의 거칠기를 모두
설명하지는 못합니다. 앰프와 포화 설정도 함께 낮춘 이유입니다.

최종 측정은 버전 간 음량 차이 0.2 dB, -14.08 LUFS, WAV와 재디코딩한 MP3의
피크 -1.30 dBTP, PLR 12.78 dB입니다. 원시 스템의 풀스케일 평탄 구간과
모노 호환성 경고는 없고, 21개 스템 모두 새 부동소수점 렌더러로 갱신했습니다.
렌더러 개선은 재사용 가능한 클라우드 설치 설정 초안에도 저장했습니다.

참고 음원과 샘플 라이브러리는 결과물에 포함하지 않습니다.
악기와 권리 정보는 [CREDITS.md](CREDITS.md)에 있습니다.
