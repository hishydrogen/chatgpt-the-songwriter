# Floating scat — 1단계 사운드 팔레트

124 BPM, F장조, 스윙 재즈 팝. 짧은 스캣 모티프가 리듬을 앞질렀다가
긴 모음으로 기대고, 피아노와 관악기가 빈자리에 답한다.

보컬 후보들은 같은 8마디, 같은 노트·타이밍·강약·표현 설정과 같은 반주를
사용한다. 건반, 베이스와 드럼 후보들도 각각 같은 MIDI 연주로 비교한다.
후보별 음량은 해당 그룹의 중앙값에서 ±1 dB 안으로 맞췄다.

| 시간 | 후보 | 비교할 특징 |
|---|---|---|
| 0:00.0-0:15.5 | 보컬 A — Kumi | 또렷한 발음과 밝은 음색 |
| 0:17.4-0:32.9 | 보컬 B — Hikari | 가볍고 숨결이 있는 음색 |
| 0:34.8-0:50.3 | 보컬 C — Milk | 부드럽고 둥근 음색 |
| 0:52.3-1:00.0 | 건반 A — Yamaha C5 | 선명한 어쿠스틱 피아노 |
| 1:01.9-1:09.7 | 건반 B — Steinway | 부드러운 어쿠스틱 피아노 |
| 1:11.6-1:19.4 | 건반 C — Rhodes | 전기 피아노의 둥근 어택 |
| 1:21.3-1:29.0 | 베이스 A — 업라이트 | 어쿠스틱 워킹 베이스 |
| 1:31.0-1:38.7 | 베이스 B — 일렉트릭 | 핑거 베이스의 탄력 |

| 1:50.3-1:58.1 | 드럼 B — DRSKit | 같은 그루브의 다른 키트 |

후보 사이에는 약 2초의 짧은 턴어라운드가 있다. 보컬만 비교하는 파일은
`out/voices.mp3`, 전체 팔레트는 `out/master.mp3`다.

## 세션

31트랙, 노트 2,246개. 보컬 후보 3개, 피아노 후보 3개, 베이스 후보 2개,
드럼 후보 2개와 공통 밴드 세션으로 구성했다. 드럼은 킥, 스네어, 라이드,
페달 하이햇, 톰으로 분리했다. 기타, 봉고와 셰이커, 트롬본, 호른,
뮤트 트럼펫, 테너 색소폰이 보컬의 빈자리를 받는다.

- 스캣 훅은 음절 49개, C4-Bb4 음역이다. 강박·긴 음의 화성 적합성을 검사했다.
- 피아노는 루트리스 보이싱, 성부 이동, 분산 어택과 짧은 페달을 사용한다.
- 베이스는 F#-G, Db-C, Ab-A의 연결음으로 다음 화음을 예고한다.
- 드럼은 라이드의 강약, 뒤에 놓인 백비트, 고스트 노트와 프레이즈별 필인을 사용한다.
- 보컬 MIDI에는 스캣 음절을 로마자로 넣었고, 피치 벤드와 비브라토를 포함한다.
- 전체 MIDI는 같은 역할의 순차 후보가 채널을 공유하며, 동시 악기의 컨트롤러가
  서로 간섭하지 않도록 채널을 지정했다. 각 트랙의 악기 ID도 MIDI에 들어 있다.

## 검증

`score-check.json`은 화성, 음성 샘플 매핑, 동일 연주와 MIDI 채널 검사의 결과다.
`out/vocal-pitch.png`는 실제 보컬 피치와 MIDI를 비교한다. 3개 보컬 모두
음정 중앙 오차 1센트 이하, 80센트 이상 이탈한 음 없음. Kumi에서 검출된
한 개의 파형 점프는 3.3716초, `だ` 모음 시작 22ms 전의 자음 구간에 있다.

최종 마스터는 약 -14.1 LUFS, -1.0 dBTP, PLR 13.1 dB이고 기술 경고가 없다.
각 후보 그룹은 음량 허용 범위를 통과했다. 전 구간을 합친 마스킹 표의
보컬 후보 간 중첩은 서로 다른 시간에 재생되는 후보의 통계이므로, 보컬
구간별 반주 레벨을 따로 확인했다.

## 다시 만들기

프로젝트 루트에서 실행한다.

```bash
bash scripts/studio.sh --python songs/scat-jazz-palette/check_score.py
bash scripts/studio.sh build songs/scat-jazz-palette
bash scripts/studio.sh --python scripts/audition_levels.py songs/scat-jazz-palette
bash scripts/studio.sh --python songs/scat-jazz-palette/check_pitch.py
```

후속 단계에서는 보컬과 반주 음색을 선택한 뒤 같은 훅으로 그루브 스케치를 만든다.
