# Low Tide — credits

Codex the Songwriter, 2026. Original instrumental, 3:30, 86 BPM, E minor.

- Composition, arrangement and programming: Codex for hishydrogen.
- Style reference: The Beatles, “Come Together” (1969); user supplied the 2019 mix.
  Analysis only. No reference audio, riff or melody is sampled or reused.
- Choices: BBBB instruments, groove A throughout, about 3 minutes 30 seconds.
- Virtuosity Drums — Versilian Studios / Karoryfer. CC0 1.0.
  https://github.com/sfzinstruments/virtuosity_drums
- Black and Blue Basses — Karoryfer. CC0 1.0.
  https://github.com/sfzinstruments/karoryfer.black-and-blue-basses
- Wurlitzer EP200 — Greg Sullivan, SFZ mappings by kinwie. CC BY 3.0.
  https://github.com/sfzinstruments/GregSullivan.E-Pianos
  https://creativecommons.org/licenses/by/3.0/
- Emily guitar — D. Smolken / Karoryfer, direct recordings of an Epiphone guitar.
  Upstream permits royalty-free commercial and non-commercial use.
  https://github.com/sfzinstruments/karoryfer.emilyguitar
- Rendering: sfizz with float WAV output. Guitar amp: guitarix.
  EQ/compression/limiting: LSP. Reverb: Dragonfly. Gentle tape colour: repository DSP.
- Mixing and mastering: Codex in the repository studio. Approved checkpoint-3
  PCM retained for the final master; -14.08 LUFS / -1.30 dBTP, PLR 12.78 dB.
- Original sleeve image and typography: OpenAI image generation. 1254 px source,
  exported at 3000 px for the sleeve and embedded metadata; see `art/README.md`.

Period tone is approximated using these sampled instruments and digital processing.
Raw sample libraries and the uploaded reference are not redistributed.
Released as `Low Tide`, with the existing full-stop ending retained for checkpoint 4.
Both ALAC versions and the MP3 carry the title, artist, year, BPM, instrument
credits and the complete sleeve. The 24-bit ALAC is bit-exact to the approved WAV;
the 16-bit edition is resampled to 44.1 kHz and dithered with SoX.
