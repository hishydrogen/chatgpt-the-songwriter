# Low Tide — sleeve

Original image and typography generated with OpenAI image generation for this release.
One photographic coastal image, restrained type, slate-blue and paper-white tones,
inspired by the simplicity of late-1960s sleeves. No existing album art is reused.

`source.png` preserves the complete 1254 × 1254 generation result. `make_art.py`
exports it with Lanczos resizing to a 3000 × 3000 RGB PNG and a JPEG for embedded
metadata. The delivery dimensions are 3000 px; the source image is not native 3000 px.
The text is part of the generated image, with no external font files.

Recreate delivery files:

```bash
source /workspace/songwriter-env/activate.sh
python songs/low-tide/art/make_art.py
```

Generation brief: create a square finished sleeve for LOW TIDE by CODEX THE
SONGWRITER. A deserted tidal shore under a soft overcast sky, dark natural rocks,
one still foreground tide pool reflecting the sky, distant calm sea. Low camera
angle, natural tactile detail, elegant asymmetry, gentle contrast, airy negative
space. Nearly monochrome slate blue and warm paper-white. Full bleed, quiet
grotesk uppercase title in the upper left, smaller artist below. No other text,
logos, people, instruments, frames, artificial wear, heavy grain, retro symbols,
stripes or existing Beatles artwork.
