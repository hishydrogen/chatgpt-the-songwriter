# Low Tide — 체크포인트 3

사용자가 선택한 **BBBB 악기 + A 그루브만**으로 만든 전체 인스트루멘털 러프 믹스입니다.
작업 제목은 `Low Tide`이며, 제목과 최종 엔딩은 이 단계에서 정합니다.
현재 미리듣기는 마지막 화음을 남기고 끝내는 완결형 엔딩입니다.

## 들어보기

[전체 러프 믹스 MP3](out/master.mp3) / [24비트 WAV](out/master.wav)

86 BPM, E단조, 74마디이며 잔향을 포함해 약 3분 30초입니다.
드럼과 베이스의 기본 리듬은 모든 섹션에서 A로 유지합니다. 스네어를 약간 늦게 둔
느긋한 뒤박과 짧은 베이스의 리듬을 중심으로 멜로디, 화성과 강약을 발전시킵니다.

| 시작 | 구간 | 전개 |
|---|---|---|

| 0:45 | 후렴 1 | 길어진 기타 멜로디와 조용한 기타 화음 |
| 1:07 | 연결구 | 중심 리프로 돌아갈 여백 |
| 1:13 | 주제 2 | 리프를 다시 들려주고 마지막 구절을 확장 |
| 1:46 | 후렴 2 | 같은 뒤박에서 연주 강도를 높임 |

원곡의 음원, 베이스 리프와 멜로디를 재사용하지 않습니다. 악기는 빈티지 마이크 드럼,
Darkblack 손가락 베이스, Wurlitzer EP200, Emily 기타입니다. 후렴의 작은 기타 화음과
건반 응답도 같은 선택 악기로 연주합니다. 새 악기나 다른 그루브를 추가하지 않습니다.

## 소리가 찢어지지 않도록 한 설정

기타 앰프는 체크포인트 2의 낮춘 입력과 드라이브(`PreGain -8 / Distortion 4 / Drive 0.08`)를
유지합니다. 테이프 포화는 조금만 섞고, 전체 출력 피크 목표는 -1.3 dBTP입니다.
중간 샘플 렌더링은 32비트 부동소수점으로 유지해 믹싱 전에 양자화하거나 잘리지 않도록 합니다.
리드와 건반의 중저역을 정리하고 짧은 룸/플레이트 잔향을 사용합니다.

실제 길이는 **3분 29.512초**입니다. 미리듣기는 48 kHz / 320 kbps MP3이고,
로컬 WAV는 48 kHz / 24비트입니다. WAV와 MP3를 다시 디코딩한 결과 모두
**-14.08 LUFS / -1.30 dBTP**로, 출력 피크에 여유를 남겼습니다.
PLR은 **12.78 dB**, 스테레오 상관도는 **0.987**이며 모든 원본 스템에서
풀스케일 평탄 구간이 0개였습니다. 자동 기술 경고도 없습니다.

마스킹 참고 항목에는 킥-베이스의 저역, 스네어-기타의 중역이 함께 표시됩니다.
베이스 중심의 편성에서 공유하는 대역이며, 중저역 EQ와 리드의 쉼표로 공간을
두었습니다. 이 측정은 음색이나 멜로디에 대한 청취자의 판단을 대신하지 않습니다.

## 재현과 검증

```bash
source /workspace/songwriter-env/activate.sh
cd /workspace/chatgpt-the-songwriter
python songs/low-tide/build.py
python songs/low-tide/build.py --validate-only
```

작곡 단계에서 악기 음역과 멜로디-화성 관계를 확인합니다. 빌드는 현재 소스와 MIDI의
일치, 모든 스템의 부동소수점 렌더링, 풀스케일 평탄 구간, WAV와 MP3 재디코딩 후
피크, 음량, 다이내믹과 모노 호환성을 검사합니다. 기술 리포트는 `out/report.json`과
`out/report.png`, 검증 기록은 `out/validation.json`에 있습니다.

이 단계는 전체 구성과 멜로디를 듣고 고르는 러프 믹스입니다. 최종 믹스, 앨범 아트,
태그가 붙은 무손실 음원은 다음 체크포인트에서 준비합니다.
